\# MediCore Healthcare Lakehouse



\## Project Overview



MediCore is a fictional multi-hospital healthcare organisation.



This project builds a modern data platform using Microsoft Azure and Databricks.



\## Technology Stack



\- Azure Data Factory

\- Azure Data Lake Storage Gen2

\- Azure Databricks

\- Auto Loader

\- Delta Lake

\- Unity Catalog

\- Power BI

\- GitHub Actions

\- Terraform

\- Azure Logic Apps



\## Data Architecture



Bronze → Silver → Gold



\- Bronze: Raw source data

\- Silver: Cleaned and validated data

\- Gold: Business-ready analytical data



\## Project Goals



1\. Build reusable ingestion pipelines.

2\. Implement metadata-driven processing.

3\. Apply data quality checks.

4\. Build fact and dimension tables.

5\. Implement incremental loading.

6\. Automate testing and deployment.



\## Source Data



The initial learning dataset contains 5,000 rows and 49 columns.



It is a sample Oracle ERP-style CSV extract, not a live Oracle connection.



\## Security



Never commit real patient information, passwords, credentials or confidential source data to GitHub.
